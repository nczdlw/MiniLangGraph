### 经验/坑
- 本机 git 凭据助手为 GCM（`credential.helper=manager`），无明文 `~/.git-credentials`、无 SSH 私钥、cmdkey 无 github 缓存；`git push` 靠 GCM 弹窗/凭据完成认证。`GIT_TERMINAL_PROMPT=0` 会让其免交互失败。
- 私有仓库**不进公共搜索**（`search_repositories` 对 user 私有仓 `total_count=0`），不能据此判断仓库是否存在。
- MCP `create_repository` 对当前 GitHub 集成返回 `403 Resource not accessible by integration`——连接器无建仓库作用域，需用户重新授权或手动建仓。
- 走沙箱外执行网络操作（git push/ls-remote）需 `dangerouslyDisableSandbox=true`。
